## About

Single-file portfolio for **Nour EL KAMEL**, AI Research Engineer at SLB AI Lab (Paris).  
Built with vanilla HTML/CSS/JS — no frameworks, no build step, instant load.

**Sections:** Hero · About · Research Interests · Experience · Projects · Publications · Education · Skills · Contact

## Features

- Animated canvas starfield with twinkling stars and shooting stars
- Floating nebula blobs (CSS radial gradients + keyframe animation)
- Scroll-reveal on all cards via `IntersectionObserver`
- Sticky nav with active-section highlighting
- Fully responsive

## Stack

```
HTML · CSS · Vanilla JS · Google Fonts (Space Grotesk + Space Mono)
```

No npm. No build. Open `index.html` in a browser.
